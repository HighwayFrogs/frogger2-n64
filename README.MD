# Frogger 2: Swampy's Revenge (Cancelled Nintendo 64 Port)  
This is a backup of Frogger 2's official source code with the common folder being from March 2000, and N64 being from December 1999.  
The N64 version was cancelled, and this is believed to be the last if not very close to the last N64 code changes.  
This code has been modified to make it easier to build, and so that it can actually build successfully.  

**Developer:** Blitz Games  

## How to compile and run?  
Run `make.bat`. Choose your region.  
When it finishes, there will be a N64 ROM in `BUILD\`.  
Compilation has been tested under Windows 10.
